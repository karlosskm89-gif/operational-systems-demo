# Screenshot Guide

## vNext note — 13 September 2026

The existing PNG files under `/screenshots` pre-date the flexible-intake refit and are retained as historical proof assets. They should be refreshed from the deployed vNext application before being reused in portfolio/public material.

Recommended vNext screenshot structure:

```text

  /public-flow
  /admin
  /workflow
  /mobile
```

## Capture rules

Use:

- the deployed vNext application
- clean browser screenshots
- realistic fictional demo records only
- `.webp` where possible
- consistent crops
- mobile and desktop views

Avoid:

- browser bookmarks/tabs
- private accounts
- real client data
- prospect-specific branding or names
- blurry compression
- giant full-page screenshots unless needed
